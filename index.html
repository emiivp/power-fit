¿Qué es PowerFit?

PowerFit es una aplicación de administración para Iron Core Fitness Center, diseñada para facilitar la organización de la información de los clientes.

El sistema permite registrar clientes, consultar información, administrar membresías, registrar pagos, generar rutinas y consultar estadísticas.

La aplicación web funciona como una representación visual e interactiva de las funciones principales desarrolladas originalmente en Python.
