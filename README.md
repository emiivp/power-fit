# PowerFit

## Sistema de gestión para Iron Core Fitness Center

PowerFit es un sistema de administración desarrollado en Python para facilitar la organización de la información de los clientes de Iron Core Fitness Center.

El sistema permite administrar clientes, membresías, pagos, objetivos de entrenamiento, generación de rutinas y estadísticas.

## Funciones principales

* Registrar clientes.
* Buscar clientes.
* Mostrar clientes registrados.
* Consultar información completa.
* Editar información de clientes.
* Eliminar clientes.
* Registrar pagos.
* Administrar membresías.
* Generar rutinas de entrenamiento.
* Consultar estadísticas.
* Manejar información mediante listas y diccionarios.
* Validar datos ingresados.
* Manejar errores mediante `try` y `except`.

## Objetivos de entrenamiento

PowerFit permite generar rutinas de acuerdo con diferentes objetivos:

* Ganar masa muscular.
* Pérdida de grasa.
* Mejorar condición física.
